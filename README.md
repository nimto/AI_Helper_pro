## Features

### 🤖 Unified AI Tools
- **Claude Code** - Anthropic Claude-based coding assistant
- **Gemini CLI** - Google Gemini AI terminal tool
- **Codex** - OpenAI Codex-based code generation

### 📊 Dashboard
- AI usage statistics at a glance
- Community activity status
- Social (followers/following) information
- Recent activity timeline

### 📚 Library
- Integrated project file management
- Image preview and optimization
- Various file format viewers (Markdown, Code, JSON, etc.)
- Folder tree navigation and search

### 🌍 Multi-language Support
- Korean (ko)
- English (en)
- Japanese (ja)
- Simplified Chinese (zh-CN)
- Traditional Chinese (zh-TW)
- Filipino (tl)

### 🎨 UI/UX
- Dark mode by default
- Responsive layout
- Customizable settings

## System Requirements

### Windows
- **OS**: Windows 10 or later (64-bit)
- **RAM**: 4GB or more recommended
- **Disk**: 500MB or more free space

## Installation

1. Download the latest version from the download link above
2. Run the downloaded `AI Helper Pro-Windows-Setup.exe`
3. Follow the installation wizard to complete the installation
4. Launch from the Start menu or desktop "AI Helper Pro" icon
